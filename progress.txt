### PRD-005: Implement NWS API client for alerts and backup data
- **Completed**: 2026-01-28
- **Files changed**:
  - src/services/nwsApi.ts (created)
- **Decisions made**:
  - Uses NWS api.weather.gov endpoints (free, no API key required)
  - Implements two-step API pattern: points endpoint -> gridpoint hourly forecast
  - User-Agent header set as required by NWS API guidelines
  - fetchAlerts(lat, lon) returns active alerts for a location

  - Default values used for fields NWS doesn't provide: visibility=10mi, uvIndex=0, feelsLike=temperature
  - Coordinates rounded to 4 decimal places as required by NWS API
